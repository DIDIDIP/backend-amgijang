# 백엔드 암기장

백엔드 필수 용어 60개를 카드로 외우고, 퀴즈로 확인하고, 틀린 단어는 오답노트로 복습하는 웹 사이트입니다.

**사이트:** https://dididip.github.io/backend-amgijang/

- **카드 학습**: 몰라요 / 애매해요 / 알아요를 고르면 다음 복습 시간이 자동으로 정해지는 간격 반복 (1분, 10분, 1·3·7·21일)
- **퀴즈**: 4지선다, 세 가지 유형 (설명 → 용어, 용어 → 설명, 한국어 → 영어 용어)
- **오답노트**: 틀린 단어가 쌓이고, 다시 2번 맞히면 졸업
- **단어장**: 검색, 분야 필터, 숙련도 표시
- 분야: HTTP·네트워크, 데이터베이스, 설계·아키텍처, 보안·인증, 인프라·배포, 성능·동시성

빌드 없이 `index.html` 한 파일로 동작합니다. 학습 기록은 브라우저(localStorage)에 저장되어, 기기나 브라우저가 바뀌면 이어지지 않습니다.
